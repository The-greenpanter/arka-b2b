### Para autenticar Docker con ECR desde WSL

**Opción A — Credenciales temporales de CloudShell (más rápido):**
```bash
# 1. En AWS CloudShell:
aws sts get-session-token --duration-seconds 43200
# Copia los tres valores del output JSON

# 2. En WSL (reemplaza con los valores copiados):
export AWS_ACCESS_KEY_ID="ASIA..."
export AWS_SECRET_ACCESS_KEY="xyz..."
export AWS_SESSION_TOKEN="FwoGZX..."
export AWS_DEFAULT_REGION="us-east-1"
```

**Opción B — IAM permanent (si ya creaste el usuario IAM):**
```bash
aws configure
# Pega Access Key ID y Secret Access Key del usuario IAM
```

## Fix crítico que se hizo en docker-compose.yml

El Kafka original tenía un bug:
```yaml
# ANTES (roto — los ms no podían conectarse):
KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://localhost:9092

# DESPUÉS (correcto):
KAFKA_ADVERTISED_LISTENERS: PLAINTEXT://kafka:9092
```

> "Usamos LocalStack para simular los servicios AWS que usaríamos en producción —
> MSK para Kafka, RDS para PostgreSQL, S3 para almacenamiento de reportes. Nuestro
